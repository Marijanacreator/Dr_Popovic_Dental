# Stomatološki centar Popović — GitHub Pages

1. Raspakujte ZIP i prenesite index.html, assets, images i .nojekyll u koren GitHub repozitorijuma. Nemojte postavljati sam ZIP ili dodatni nadređeni folder.
2. Otvorite Settings → Pages → Build and deployment.
3. Izaberite Deploy from a branch, granu main i folder / (root), pa Save.
4. Kada se objavljivanje završi, otvorite adresu iz Settings → Pages.

Sajt je već izgrađen. Nisu potrebni npm, React build ni GitHub Actions.
Putanje do fajlova su relativne, pa paket radi i na Pages adresi sa imenom repozitorijuma.
